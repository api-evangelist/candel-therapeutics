# Candel Therapeutics

> Candel Therapeutics, Inc. (Nasdaq: CADL) is a clinical-stage biopharmaceutical company in
> Needham, Massachusetts developing off-the-shelf multimodal viral immunotherapies for solid
> tumors. Founded as Advantagene. Candel is a therapeutics developer, not a software vendor.

## No API surface

Candel Therapeutics publishes **no public API**. As of 2026-09-09 there is no developer
portal, no API reference, no OpenAPI/AsyncAPI/GraphQL/Protobuf/WSDL contract, no SDK in any
public package registry, no MCP server, no A2A agent card, and no `/.well-known/` document on
any host the company controls. Every contract-discovery path probed on candeltx.com returned
a real HTTP 404. Do not attempt to call an API here; there is nothing to call.

The company's only credentialed surface is a clinical-trial **investigator portal**, reached
through a login on its HubSpot-hosted marketing site. It is for named clinical-trial
investigators, not for programmatic integration.

Note: `advantagene.com`, the company's former domain, is no longer under company control and
now serves unrelated third-party content. Ignore anything found there.

## Programs

- aglatimagene besadenovec (CAN-2409): replication-defective adenovirus delivered
  intratumorally with a prodrug to induce immunogenic tumor cell death.
- linoserpaturev (CAN-3110): replication-competent oncolytic herpes simplex virus.
